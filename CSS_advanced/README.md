# CSS Advanced — Techium

A progressive CSS project covering selectors, the cascade, custom properties, typography, layout, themes, pseudo-classes, pseudo-elements, and transitions.

## Project structure

- `index.html` — Techium homepage markup.
- `styles/1-style.css` through `styles/32-style.css` — cumulative solutions for tasks 1–32.
- `images/` — project image assets (logos, favicon, and photography).

## Preview

Open `index.html` in Chrome. The page links to the final stylesheet, `styles/32-style.css`.

## Notes

- Each stylesheet builds on the preceding task.
- Google Fonts are loaded by the HTML document.
- The assignment targets Chrome 78.
